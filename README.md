# AccessLayer

Making digital experiences easier for everyone.

## About the Project

AccessLayer is a Chrome browser extension designed to make confusing websites easier to understand and navigate.

It aims to help people facing:
- Difficulty understanding complicated website forms.
- Language and technical barriers.
- Difficulty navigating websites using a keyboard.
- Accessibility challenges while interacting with digital services.

## Features

- **Guided Assistance:** Step-by-step guidance through supported forms.
- **Plain-Language Explanations:** Explains confusing form fields in simpler language.
- **Field Highlighting:** Highlights the field currently being explained.
- **Keyboard Accessibility:** Supports visible keyboard focus indicators.
- **Demo Website:** Provides a sample application form to demonstrate the features.
